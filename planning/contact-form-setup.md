# Contact form delivery

The form posts to FormSubmit for hello@verdelandscapes.com. Its default CAPTCHA stays enabled. No passwords or API keys are stored in the repository.

Before launch, submit one clearly labeled test inquiry and confirm the activation email in that mailbox. Then submit a second test and verify it arrives. Delivery has not been verified; the site remains a noindex preview. No activation email was sent by the agent.

The form uses native required-field and email validation and a normal POST, so JavaScript is not required. Do not disable CAPTCHA or show a local success message before the provider accepts the submission.
